## Контекст

Заказчик — Сергей — обратился с идеей приложения PetPal: помочь владельцам питомцев структурировать уход и распределить задачи внутри семьи. На основе текстового описания и записи встречи подготовлены артефакты для старта разработки.

## Что внутри

### [Анализ вводных](Анализ_PetPal.md)

- Цели приложения (бизнес и пользователь)
- Целевая аудитория — первичная и вторичная
- Продуктовые ограничения (платформы, рынок, сроки)
- Критерии готовности MVP
- Идеи вне скоупа первой версии
- Пользовательские истории по 5 эпикам (A–E)
- Walking Skeleton
- Открытые вопросы к заказчику

Все тезисы привязаны к тайм-кодам расшифровки встречи.

### [User Story Map](https://miro.com/welcomeonboard/cjFEajhCZzhab0Y4TUc4WnVSeWgwU3BXcWI1YkJBMHB5Z1hmRmpSKzhoQ0F0bFVnR1l5aUprQlhDUFJLNDRkYXNRWkg0alh3U08yN1BzUm5DTHprR0tRVWsxUVZ6YVRZRUpSQ0FZUHJYWTFFMklkTk1uQ2lvOWdzM1Y4a3I5Z2xQdGo1ZEV3bUdPQWRZUHQzSGl6V2NBPT0hdjE=?share_link_id=915301293466)

Построена по методологии Jeff Patton. Три уровня: User Activities → User Tasks → User Stories. Три полосы релизов: MVP (15 историй), Release 2 (7 историй), Later (6 историй). Отдельно выделен Walking Skeleton — минимальный сквозной поток A1 → B1 → C1 → D1 → D3 → D2.

### [Спринт-план](Спринт_план.md)

35 задач на два недельных спринта по методологии Scrum:

- **Спринт 1** — регистрация и вход (17 задач): продукт, дизайн, backend, Flutter, QA, маркетинг
- **Спринт 2** — профиль питомца (18 задач): полный CRUD питомцев

Для каждой задачи: название, цель, тип, приоритет, зависимости, оценка в часах. Включён capacity-расчёт по ролям, Definition of Done, Sprint Goals, риски и митигации.

### [Борда в YouGile](https://en.yougile.com/board/6utr4hdf5b2p)

Все 35 задач на доске с колонками Backlog / To Do / In Progress / Review / Done. На каждой карточке — стикеры приоритета, спринта и типа. В описании — цель и связанные user stories.
